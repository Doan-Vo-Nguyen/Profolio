# Doan Vo Nguyen — Portfolio

Minimal black-and-white personal site for Doan Vo Nguyen, fullstack developer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## GitHub Pages

Site URL: [https://doan-vo-nguyen.github.io/Profolio/](https://doan-vo-nguyen.github.io/Profolio/)

1. Push `main` to GitHub.
2. Repo **Settings → Pages → Build and deployment → Source**: chọn **GitHub Actions** (không chọn Deploy from a branch).
3. Mở tab **Actions**, chờ workflow **Deploy to GitHub Pages** chạy xong.
4. Mở đúng URL có `/Profolio/` ở cuối.
